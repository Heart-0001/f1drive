
################ ui.js + index.html (v6)

== summary
I built the v6 menu and HUD in js/ui.js and index.html, following the contract's "js/ui.js + index.html (v6)" section. Every v5 feature still works.

- **Script order:** index.html has exactly the contract's final v6 order.
- **Telemetry:** #hud-speedo is gone. A <canvas id="hud-telemetry"> sits at the bottom centre, 520 px wide at 1280 and 780 px at 1920 (the telemetry owner's size), capped at 100vw-32px. ui.init calls F1.telemetry.init once, and updateHUD hands its own object (no copy) to F1.telemetry.draw every frame. setTrack calls F1.telemetry.reset().
- **Layout around the graphic:** the key hint moved to the bottom right, beside the graphic, and wraps as needed. Below 1000 px wide only the 選單 button stays, under the minimap. The results overlay is centred in the space above the graphic; 16 rows still fit at 1280x720 without scrolling. Below 1120 px wide the session box and roster box are capped above the graphic.
- **Side panel:** now has tabs 車輛 / 大獎賽 / 多人連線 / 設定. The open tab is remembered; the default is 大獎賽 so the existing harnesses' real mouse clicks on #gp-start still land. A session starting brings 大獎賽 to the front.
- **車輛 tab:** a 年份 select (newest first) and 12-car card lists. Each card has livery chips, zh+en team, car, engine, five rating bars (電池 hidden when the car has no ERS), the note and an 已選 highlight. The lock banner, the 'estimates from public data' line and the F1DB (CC BY 4.0) credit are there. The head credit line now reads 'OpenStreetMap … ‧ 賽季資料 F1DB（CC BY 4.0）'. The head key hints are now a compact key-map table with the new keys and controller buttons.
- **大獎賽 tab:** a year + car line with a 換車 button, and a 輪胎損耗 ×1..×5 control. onGpStart({q, r, wear}). The year is shown in the tab, the HUD session box and the results subtitle; the wear shows during a session. Standings and results rows show row.colour2 chips and row.team names when present.
- **Pit strip:** new setPit() strip above the graphic.
- **設定 tab:** volume slider and mute switch, stored in 'f1drive.audio'.
- **Harnesses:** new devtests/ui-v6/shots.js with 124 checks and screenshots, all of which I read. New devtests/ui-v6/with-stubs.js serves an empty script for project scripts not written yet, so other harnesses can boot. I updated devtests/ui-gp/shots.js only where the DOM legitimately changed.

== apiNotes
 - F1.ui.init(opts) gains onYear(year), onCar(id) and onAudio({volume, muted}). onGpStart now receives {q, r, wear}, where wear is an integer 1..5 (default 1). init still calls onProfile last. init also calls F1.telemetry.init(#hud-telemetry) when F1.telemetry exists; if it is missing, the canvas simply stays empty.
 - F1.ui.setCars(v): v = {year, cars: CarSpec[] (F1.cars.list(year), standard car first), selected: id, canPickYear, canPickCar, seasons: F1.cars.seasons, reason}. A missing flag counts as true. seasons is shown newest first; v.year is added if it is missing from seasons. Cars whose id fails /^[a-z0-9-]{1,40}$/ or is a duplicate are skipped. All texts are escaped.
 - setCars, continued: the ERS bar is hidden when spec.ers === null. If spec.ers is undefined, the bar shows only when ratings.ers is a number. setCars may be called before init; the view is rendered at init. Identical calls touch no DOM (measured: 0 mutations over 50 calls). Call it on change, not every frame.
 - Addition to the contract (parc fermé): while setGp's phase is not 'free', the UI locks the year and car controls itself, whatever the flags say, and shows 賽事進行中不能換車. It unlocks when the phase returns to 'free'.
 - Default lock texts when no reason is given: both locked -> '賽事進行中不能換車'; year only -> '年份由房主選擇，大家都從這一年的車裡挑。'; car only -> '現在不能換車'.
 - Selection: clicking a card highlights it at once, stores it and calls onCar(id); clicking the already-selected card does not call onCar again. The next setCars.selected decides the highlight, so main.js may pass a resolved id. Changing the year select calls onYear(y), stores it and dims the list (.pending) until a setCars arrives. setCars.year is authoritative: the select snaps back to it.
 - getCar() -> the id the player clicked last, or null. getYear() -> the year the player picked last (integer 2010..2100), or null. Both are stored in localStorage 'f1drive.car' = {year, car} and validated on load. Neither follows setCars: they are the player's own preference. main.js resolves with F1.cars.resolve(getCar(), year), falling back to DEFAULT_YEAR when getYear() is null.
 - getAudio() -> {volume 0..1, muted}; the default is {0.8, false}, stored in 'f1drive.audio'. setAudio({volume?, muted?}) is for the M key: it clamps, ignores junk, updates the 設定 tab and stores the values, but does NOT call onAudio. The UI does not call onAudio at init, so main.js must apply getAudio() to F1.audio at boot or on audio init.
 - F1.ui.setPit(p), called every frame: p = {inLane, limiter, speeding, service: null | {left, total, penalty}, limitKmh, boxAhead, slot, pending?}. pending (optional, an addition) = seconds of hold waiting for the next stop (pit.state.pending); it shows '下次停站罰停 +N s'. The strip shows while inLane, limiter or service is set; setPit(null) hides it. Values are quantised (whole metres, 0.1 s countdown, the bar moves with the tenths), so identical input causes 0 mutations and a 3.1 s service about 69 mutations over 187 frames.
 - setPit texts: '維修區 限速 N'; '限速器 開/關'; in the lane with the limiter off: a flashing red chip plus '請開啟限速器（Q）', or '（LB）' when setPad says a pad is connected; speeding: '超速！罰停 +5 s', flashing; '你的維修格 {slot+1} 號：前方 N m / 到了，停車 (|boxAhead|<=2.5) / 已超過'. Service: '換胎中 2.3 s', or '罰停中' while left > total - penalty, plus a progress bar and '罰停 +5 s' when penalty > 0.
 - updateHUD(h): speed / gear are no longer DOM text. The same h object goes to F1.telemetry.draw, which reads speedKmh, gear (-1 / 0 / 1..9 as numbers; v5 main.js still passes 'N' / 'R' strings, which telemetry draws as N), rpm*, throttle, brake, battery (null = no ERS), deploy, harvest, limiter, inPit, limitKmh, tyres, nextCompound, team, car, colour, colour2. Reuse one h object.
 - setGp view additions it reads: view.year (shown in the panel, the HUD session box #hud-gp-year and the results subtitle; falls back to setCars.year when null) and view.wear (panel car line and results subtitle when > 1). Optional row.team (string) and row.colour2 ('#rrggbb') on standings / results rows.
 - New DOM ids: hud-telemetry; hud-pit, hud-pit-limit, hud-pit-lim (class on / off / warn), hud-pit-warn (class hot when speeding), hud-pit-box, hud-pit-pending, hud-pit-svc, hud-pit-svc-label, hud-pit-svc-time, hud-pit-bar, hud-pit-pen; hud-gp-year; menu-tabs, tab-car, tab-gp, tab-mp, tab-set, tab-car-chip, tab-gp-dot, tab-mp-dot; the pages car-panel / gp-panel / mp-section / set-panel.
 - New DOM ids (continued): car-year (select), car-season, car-lock, car-list, car-empty; gp-car, gp-year, gp-car-name, gp-car-change, gp-wear, gp-wear-note; set-volume (range 0..100), set-volume-val, set-mute (checkbox), set-mute-text; keys-kb (keys-pad and pad-status are kept).
 - Selectors for tests: '#car-list .car-card[data-id="2026-mclaren"]' (class on = chosen; #car-list.locked / .pending), '#gp-wear button[data-w="3"]' (class on), '.menu-tabs button[data-tab=car|gp|mp|set]' (class on).
 - Removed ids: hud-speedo, hud-speed, hud-gear. The multiplayer h2 '多人連線' became the tab label, and the section starts with h3 '名稱與車色'. All v5 ids are kept.
 - localStorage keys: 'f1drive.gp' is now {q, r, wear}; new keys 'f1drive.car' {year, car}, 'f1drive.audio' {volume, muted} and 'f1drive.menu' {tab}. Every one is validated on load: junk falls back to null / defaults, wear is clamped to 1..5, an unknown tab gives 大獎賽.
 - What main.js must do (1): boot: y = ui.getYear() valid ? it : F1.cars.DEFAULT_YEAR; spec = F1.cars.resolve(ui.getCar(), y); then ui.setCars({year: y, cars: F1.cars.list(y), selected: spec.id, canPickYear, canPickCar, seasons: F1.cars.seasons}).
 - What main.js must do (2): call setCars again on onYear / onCar (offline immediately; online host: net.setYear then wait for the 'year' event), on net 'year', on connect / disconnect (guest: canPickYear false), and on gp phase changes. Apply getAudio() to F1.audio.
 - What main.js must do (3): on the M key, toggle F1.audio and then call ui.setAudio({muted}). Ignore Q / E / T / M while a text field in the menu has focus (#mp-name, #track-search, #gp-q / #gp-r, #mp-addr).
 - What main.js must do (4): call ui.setPit(...) every frame; pass pending: st.pending to show the waiting hold. Pass the telemetry fields in the HUD object. Optionally add row.team / row.colour2 to the view rows.
